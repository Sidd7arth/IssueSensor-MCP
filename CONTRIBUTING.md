# Contributing

1. Open an issue describing the bug or proposed improvement.
2. Keep changes small and add tests for safety-sensitive behavior.
3. Run `pytest -q tests` and `python -m compileall -q server.py`.
4. Do not include credentials, real `.env` files, private source code, or model weights.
5. Clearly label verified facts versus AI-generated hypotheses in any new triage output.

By submitting a contribution, you agree that it may be distributed under the repository's MIT license.
